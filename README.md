# AdminFlow – E-Commerce Admin Dashboard

AdminFlow is a responsive e-commerce admin dashboard built with HTML5, CSS3, and JavaScript. It provides an interactive interface for managing products, orders, customers, analytics, and application settings.

This project was built as part of my Front-End Developer portfolio to demonstrate responsive UI development, JavaScript DOM manipulation, CRUD functionality, localStorage, filtering, and dashboard design.

## Features

- Responsive and mobile-first dashboard
- Product management with CRUD functionality
- Order management and status updates
- Customer management
- Sales and revenue analytics
- Search, filtering, and sorting
- Dark and light mode
- LocalStorage data persistence
- CSV data export
- Dashboard settings
- Help Center and FAQ section
- Responsive sidebar navigation
- Interactive notifications and modals

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage
- Responsive Web Design
- Mobile-First Development
- DOM Manipulation
